From "garbage man" to engineer

When I was little I wanted to be a garbage man. That idea grew up with me. Now I want to study engineering and build a company that cleans up space debris, the leftover junk in Earth's orbit.

I got into code by building things. I completed a full-stack developer internship, where I built React apps with user accounts and shipped them to the web. Then I put those skills to work for real people, starting with a website for my family's commercial cleaning business.

Through Running Start I took college chemistry, physics and calculus while finishing high school. Off the keyboard you'll find me on the judo mat.
